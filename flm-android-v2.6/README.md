# FLM Android v2.6 Embedded

Tek APK içinde:
- Chaquopy Python 3.13 runtime
- FLM v2.5 symbolic/semantic Python core
- 69,724-fact semantic dataset
- native Android chat UI
- root/ADB/Termux gerektirmeyen Accessibility Computer Use

Sunucu adresi, pair code ve Termux bridge yoktur. Android Accessibility izni yalnız Computer Use için Android tarafından bir kez kullanıcı onayıyla açılır.
